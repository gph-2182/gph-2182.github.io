Welcome! This course teaches R programming for the full data-analysis workflow: wrangling, visualization, simulation, and reproducible reporting with Quarto, using public-health data throughout. You will also learn two skills that now define professional statistical programming: managing code with Git and GitHub, and using AI coding assistants responsibly (prompting, verifying, and debugging AI-generated code).

No prior programming or statistics experience is required.

How the course works

  • Hands-on classes. Every session alternates short live-coding demos with paired exercises, so you write code in every class.
  • Instant feedback. Weekly exercises are submitted on GitHub and checked automatically: push your work, see which questions pass, revise, and resubmit until the deadline.
  • AI, embraced and verified. AI tools are allowed on homework and the project (with disclosure), taught explicitly in Week 8, and set aside during short in-class quizzes where your own fluency is certified.
  • One real project. The course builds to an individual analysis of a public-health dataset: a reproducible Quarto report, a GitHub repo, and a 5-minute video walkthrough.
