2 Exercise 2: A Reusable Rate Function (Cycle 2)

counties <- tibble(
  county     = c("Bronx", "Kings", "New York", "Queens", "Richmond"),
  cases      = c(412, 655, 298, 517, 96),
  population = c(1379946, 2590516, 1596273, 2278029, 491133)
)

bad_counties <- tibble(
  county     = c("Typo County", "Swapped County"),
  cases      = c(40, 880000),
  population = c(0, 1200)
)
# 1. Write incidence_rate(cases, population, per = 100000)
# 2. Use it inside mutate() on counties to add rate_100k; then add rate_1k with per = 1000
# 3. Add stopifnot() checks at the top of the function:
#    all populations are positive, and no cases value exceeds its population
# 4. Call incidence_rate(bad_counties$cases, bad_counties$population) and read the error.
#    Then replace the stopifnot() with if (...) stop("...") checks whose messages
#    tell a colleague exactly what is wrong

3 Exercise 3: Loop to map() (Cycle 3)

site_waits <- list(
  harlem   = c(25, 40, 65, 30, 55),
  flushing = c(15, 20, 35, NA, 22),
  midwood  = c(70, 45, 90, 62),
  astoria  = c(30, 28, 41)
)
# 1. Write a for loop that computes each site's median wait (use na.rm = TRUE)
#    Pre-allocate with numeric(length(site_waits)) and index with seq_along()
# 2. Replace the loop with map_dbl() and check the two agree:
#    all.equal(unname(map_result), loop_result)
# 3. Use map_lgl() to flag sites where ANY wait exceeds 60 minutes
#    (watch out for the NA at flushing)
# 4. Use map_int() to count how many waits exceed 60 minutes at each site

4 Exercise 4: Functions + map() over Groups + AI Corner (Cycle 4)

library(r02pro)

#    and median_cm = median child_mortality (na.rm = TRUE)
# 2. Use map() over c("Africa", "Americas", "Asia", "Europe", "Oceania")
#    and list_rbind() to build one table with a row per continent
# 3. Re-run step 2 for yr = 1990 by passing yr through your anonymous function

#    List two problems with it, then write share_above(x, cutoff) that takes the

#    compute the share at cutoffs 60, 70, and 80 for 2008.
