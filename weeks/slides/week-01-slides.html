Cycle 1: R Fundamentals & Packages

R as an Interactive Calculator

You type commands into the Console; R evaluates them and prints results.

# Arithmetic
12 + 35
(100 - 32) * 5 / 9   # Fahrenheit to Celsius

# Math functions
sqrt(64)
exp(1)
log(10)              # Natural logarithm (base e)
log10(100)           # Common logarithm (base 10)

Tip

Everything after # is a comment and is ignored by R. Use comments to document your thinking!

Objects and Variable Assignment

We store values in named objects using the assignment operator <- (Alt + - or Option + -):

# Assigning a value
participant_age <- 28
height_m <- 1.75
weight_kg <- 68.5

# Using objects in expressions
bmi <- weight_kg / (height_m^2)
bmi
  • Names must start with a letter and can contain letters, numbers, _, and ..
  • R is case-sensitive (bmi \(\neq\) BMI).

Functions and Getting Help

Functions take arguments (inputs) and return an output:

# Rounding
round(bmi, digits = 1)

# Summary statistics
vals <- c(10, 20, 30, NA)
mean(vals, na.rm = TRUE)

Getting help in R:

  • ?round or help(round) — opens the official documentation.
  • example(round) — runs examples from the help page.

Cycle 2: Reproducible Reports with Quarto

Why Quarto?

❌ The Traditional Way

  1. Run code in R \(\rightarrow\) Copy table to Excel \(\rightarrow\) Paste into Word \(\rightarrow\) Export PDF.
  2. Data changes? Repeat everything manually and risk copy-paste errors!

✅ The Quarto Way

One reproducible .qmd document combining:

  • Narrative text (Markdown)
  • Executable code (R chunks)
  • Dynamic tables & plots compiled directly on demand.

Anatomy of a Quarto Document (.qmd)

A .qmd document combines three elements:

1. YAML Metadata (Header):

---
title: "My Analysis"
author: "Your Name"
format: html
---

2. Markdown Narrative (Text):

## Introduction
Here is text with **bold** & *italics*.

3. Code Chunks (Live Computation):

# An R code chunk
mean_age <- mean(c(25, 30, 45))
mean_age

\(\longrightarrow\) Click Render (Ctrl/Cmd + Shift + K) to compile directly into a polished HTML report!

Markdown Text Formatting Cheat Sheet

Syntax Rendered Output
# Heading 1 Largest Section Header
## Heading 2 Sub-section Header
**bold text** bold text
*italic text* italic text
- item 1 Bulleted list
1. item 1 Numbered list
$E = mc^2$ Inline math: \(E = mc^2\)

Code Chunk Options

Control how code executes and displays using #|:

#| echo: true       # Show code in final report (default)
#| eval: true       # Run code (default)
#| warning: false   # Suppress package warnings
#| message: false   # Suppress package startup messages
#| fig-width: 7     # Control plot width

Click the Render button (or Ctrl/Cmd + Shift + K) in RStudio to generate your HTML report!

Cycle 3: Git, GitHub, and Classroom

Why Version Control?

❌ The File Chaos (Without Git)

  • report_v1.docx
  • report_v2.docx
  • report_v2_edit.docx
  • report_final_REALLY_FINAL.docx
  • 😱 Which file has the correct numbers?

✅ The Git Way

  • Recorded history: Every change is a snapshot with a commit message.
  • Safe experiments: Try new ideas on branches without breaking main code.
  • Seamless team collaboration: No emailed zip files or overwritten work.

The Core Git Workflow in RStudio

How Homework Works (Instant Feedback)

  3. Solve: Open exercise.qmd, assign answers to q1, q2, etc.
  4. Render: Confirm the HTML compiles cleanly.
  5. Push: Commit and push to GitHub.
  6. Instant Report: Go to the Actions tab on GitHub: within 2 minutes, see which questions pass.
  7. Iterate: Revise and re-push freely until Wednesday 11:59 PM!
