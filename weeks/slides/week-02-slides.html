Cycle 1: Vector Types & Coercion

The Four Atomic Vector Types

In R, every element in an atomic vector must have the same type:

1. Numeric (Double)

Decimal numbers (default in R):

weights <- c(68.5, 72.0, 81.3)
typeof(weights) # "double"

2. Integer

Explicit whole numbers with L:

counts <- c(1L, 5L, 12L)
typeof(counts)  # "integer"

3. Character (Strings)

Text enclosed in quotes:

drugs <- c("aspirin", "statin", "placebo")
typeof(drugs)   # "character"

4. Logical (Booleans)

TRUE or FALSE (all caps):

adherent <- c(TRUE, FALSE, TRUE)
typeof(adherent)# "logical"

The Type Hierarchy & Implicit Coercion

What happens when you mix different types in c(...)?

R silently converts everything to the least restrictive type:

\[\text{logical} \longrightarrow \text{integer} \longrightarrow \text{double} \longrightarrow \text{character}\]

# Logical to numeric (TRUE becomes 1, FALSE becomes 0)
sum(c(TRUE, FALSE, TRUE, TRUE))  # Count how many TRUEs: 3
mean(c(TRUE, FALSE, TRUE, FALSE))# Proportion of TRUEs: 0.5

# Numeric + Character becomes Character
c(10, 25, "missing")             # c("10", "25", "missing")

Pro-Tip for Health Data

mean(bp > 140, na.rm = TRUE) directly calculates the prevalence of hypertension by coercing logicals to 1s and 0s!

Summary Statistics on Vectors

R has built-in vector aggregators:

chol <- c(185, 220, 240, 195, 210, NA)

length(chol)              # Total elements including NA (6)
sum(is.na(chol))          # Count missing values (1)
mean(chol, na.rm = TRUE)  # Arithmetic mean (212)
sd(chol, na.rm = TRUE)    # Standard deviation (20.8)
summary(chol)             # 5-number summary + Mean + NAs

Cycle 2: Creating Patterned Vectors

Sequences with : and seq()

Instead of typing numbers manually, generate sequences automatically:

The Colon Operator :

Consecutive integer sequences:

1:10
20:15    # Counts backward!
-3:3

The seq() Function

Flexible step sizes & lengths:

# By step size
seq(from = 0, to = 100, by = 20)
# Output: 0 20 40 60 80 100

# By total length
seq(from = 0, to = 1, length.out = 5)
# Output: 0.00 0.25 0.50 0.75 1.00

Repetition with rep()

The rep() function replicates values using times or each:

times (Pattern repetition)

Repeats the whole vector:

rep(c("A", "B"), times = 3)
# "A" "B" "A" "B" "A" "B"

# Unequal repetitions per element:
rep(c("Control", "Treated"), times = c(4, 2))
# "Control" "Control" "Control" "Control" "Treated" "Treated"

each (Element repetition)

Repeats each item before moving to next:

rep(c("A", "B"), each = 3)
# "A" "A" "A" "B" "B" "B"

# Combining both:
rep(c("Dose1", "Dose2"), each = 2, times = 2)
# "Dose1" "Dose1" "Dose2" "Dose2" "Dose1" "Dose1" "Dose2" "Dose2"

Modulo Arithmetic %%

The modulo operator %% calculates the remainder of division:

14 %% 3   # 2  (14 = 4 * 3 + 2)
10 %% 2   # 0  (10 is even)

Common Applications in Data Science

  • Even numbers: x %% 2 == 0
  • Divisible by 5: x %% 5 == 0
  • Assigning participants to \(K\) rotating study groups: (1:N) %% K + 1

Cycle 3: Subsetting & Mutating Vectors

The Three Subsetting Methods

We extract elements using square brackets x[...]:

ages <- c(23, 45, 19, 31, 56, 42)

1. Positive Indices

Extract by position (1-indexed):

ages[1]        # 23
ages[c(1, 4)]  # 23 31
ages[2:4]      # 45 19 31

2. Negative Indices

Exclude specific positions:

ages[-1]       # All except 1st
ages[-c(2, 5)] # Drop 2nd & 5th
# ages[-2:4]   # ERROR! Use -(2:4)

3. Logical Subsetting

Extract where TRUE:

ages[ages > 40]
# 45 56 42

ages[ages >= 30 & ages <= 50]
# 45 31 42

Logical Operators for Filtering

Combine conditions using element-wise logical operators:

Operator Meaning Example
& Element-wise AND (both true) (bmi > 25) & (age > 50)
\| Element-wise OR (either true) (status == "Severe") \| (fever == TRUE)
! Logical NOT (inversion) !(city %in% c("NY", "CA"))
%in% Value matching (set membership) id %in% confirmed_cases 
sbp <- c(118, 142, 135, 160, 122)
stage2_htn <- sbp >= 140
sbp[stage2_htn]   # 142 160

Modifying Vectors in Place (Mutation)

Use subsetting on the left side of <- to update specific elements:

scores <- c(88, -99, 95, -99, 72)

# Replace survey code -99 with NA:
scores[scores == -99] <- NA
scores
# 88 NA 95 NA 72

# Cap values at 90 (winsorizing):
scores[scores > 90 & !is.na(scores)] <- 90
scores
# 88 NA 90 NA 72

Cycle 4: Sorting, Ranking & AI Corner

Sorting, Ranking, and Ordering

Understanding the difference between sort(), rank(), and order():

vals <- c(30, 10, 50, 20)

sort(x)

Returns sorted values:

sort(vals)
# 10 20 30 50

sort(vals, decreasing = TRUE)
# 50 30 20 10

rank(x)

Returns rank position of each element:

rank(vals)
# 3 1 4 2
# (30 is 3rd, 10 is 1st, etc.)

order(x)

Returns indices that would sort x:

order(vals)
# 2 4 1 3
vals[order(vals)] # sorted!

Handling Ties in rank()

When numbers repeat, how should ranks be assigned?

scores <- c(80, 95, 80, 70)

rank(scores)                        # Default: average ranks (2.5 4.0 2.5 1.0)
rank(scores, ties.method = "first") # By appearance: (2 4 3 1)
rank(scores, ties.method = "min")   # Sports ranking: (2 4 2 1)

Tip

ties.method = "first" is essential for deterministic top-\(K\) rankings in data pipelines!

AI Corner: Beware Vector Recycling!

When R operates on vectors of different lengths, it silently recycles the shorter one:

What R Does:

x <- c(10, 20, 30, 40)
y <- c(1, 2)
x + y
# Computes: 10+1, 20+2, 30+1, 40+2
# Output: 11 22 31 42

⚠️ The Danger with AI:

  • LLMs often generate code that accidentally recycles vectors when filtering or standardizing.
  • Always check length(x) == length(y) before element-wise operations!
